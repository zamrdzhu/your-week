One funny line of text, written for make.fun's "Your Week in One Line" bounty.

## The line

> Shipped five features, broke six, and my coffee machine has started charging me rent.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

A week summed up as a scoreboard: five shipped, six broken, net negative — and the one reliable coworker, the coffee machine, has started charging rent. The concrete numbers make it this week and no other, the turn lands on the first read, and every word earns its place inside the 100-character gate. No template, no saying, just a week that got away from its owner. One line, 85 characters.
